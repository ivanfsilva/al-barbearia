# 💈 Barbearia Alura — Sitio Web Institucional

Este repositorio contiene el proyecto práctico de **Barbearia Alura**, desarrollado para consolidar los fundamentos esenciales del desarrollo web front-end utilizando **HTML5** y **CSS3** puro.

El objetivo principal fue construir un sitio web institucional completo y funcional para una barbería tradicional, abarcando la página de inicio, el catálogo de productos/servicios y el formulario de contacto.

---

## 🎯 Conceptos y Recursos Implementados

El proyecto aplica en la práctica los siguientes conceptos web clave:

- **Estructuración Semántica:** Uso adecuado de etiquetas HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) para mejor accesibilidad y SEO.
- **Estilizado y Modelo de Cajas (Box Model):** Manipulación de márgenes, rellenos (_padding_), bordes y alineación de elementos.
- **Diseños con CSS:** Posicionamiento de elementos, listas personalizadas y estilizado de tablas de horarios.
- **Formularios Interactivos:** Validación nativa de entradas, selectores, casillas de verificación (_checkbox_ y _radio_) y botones personalizados.
- **Diseño y Medios:** Integración de imágenes de fondo (_background-image_), transiciones CSS y una identidad visual cohesiva.
