# 💈 Barbearia Alura — Website Institucional

Este repositório contém o projeto prático da **Barbearia Alura**, desenvolvido para consolidar os fundamentos essenciais de desenvolvimento web front-end com **HTML5** e **CSS3** puro.

O objetivo principal foi construir a interface estática de um website institucional para uma barbearia tradicional, estruturando a página inicial, catálogo de produtos/serviços e formulário de contato.

---

## 🎯 Conceitos e Recursos Implementados

O projeto abrange e aplica na prática:

- **Estruturação Semântica:** Uso adequado das tags HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) para melhor acessibilidade e SEO.
- **Estilização & Box Model:** Manipulação de margens, espaçamentos (_padding_), bordas e alinhamentos.
- **Layouts com CSS:** Posicionamento de elementos, listas customizadas e estilização de tabelas de horários.
- **Formulários Interativos:** Validação nativa de inputs, seletores, caixas de seleção (_checkbox_ e _radio_) e botões personalizados.
- **Design & Mídia:** Aplicação de imagens de fundo (_background-image_), transições CSS e identidade visual coesa.
