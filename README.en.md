# 💈 Barbearia Alura — Institutional Website

This repository contains the practical project for **Barbearia Alura**, built to solidify core web development fundamentals using pure **HTML5** and **CSS3**.

The main objective was to create a complete and functional institutional website for a traditional barbershop, including a homepage, product/service catalog, and a contact form.

---

## 🎯 Implemented Concepts & Features

This project applies the following core web concepts in practice:

- **Semantic Structure:** Proper use of HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) for enhanced accessibility and SEO.
- **Styling & Box Model:** Precise management of margins, padding, borders, and element alignment.
- **CSS Layouts:** Element positioning, custom list styling, and styled business hours tables.
- **Interactive Forms:** Native input validations, dropdown selectors, custom checkboxes, radio buttons, and styled submit buttons.
- **Design & Media:** Background image integration, smooth CSS transitions, and a cohesive visual identity.
